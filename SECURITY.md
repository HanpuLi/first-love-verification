# Security policy

## Scope

This repository contains reproducibility scripts and derived analytical outputs, but deliberately redistributes no film, audio or subtitle source material.

Security-relevant reports include:

- accidentally committed third-party media, subtitles or personally identifying local data;
- credentials, API tokens, machine-local paths or private research material in the public tree or history;
- scripts that write outside an explicitly requested output directory or execute untrusted input unexpectedly;
- CI or repository-boundary changes that weaken the documented no-media rule.

## Reporting

Use GitHub private vulnerability reporting for security-sensitive findings. Do not attach copyrighted source media, private correspondence, credentials or other restricted material to a public issue.

The latest main branch receives fixes.
